# Schulkram

Einkaufsliste für Schulsachen: einfach eintippen, was auf der Liste der Schule steht, z. B. „A4 Heft Lineatur 26“. Hefte werden mit ihrer Lineatur angezeigt, Stifte und Mappen in Farbe.

**Direkt benutzen:** https://mkrgr.github.io/schulkram/

- Lineaturen 1–54 als Vorschau mit Lupe
- Menge, Format, Farbe, Härtegrad usw. werden aus der Eingabe erkannt
- Abhaken, Notizen, als Text kopieren, drucken (mit QR-Code)
- Liste per Link teilen: Die Liste steckt im Link selbst (`#1:heft.A4.26*3~…`), es wird nichts auf einem Server gespeichert. Auf dem Ausdruck führt ein QR-Code zu genau dieser Liste.
- Alles in einer Datei (`index.html`), keine Installation, die Liste bleibt im Browser gespeichert
